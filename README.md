# CAO Points Explorer dashboard
CAO Points Explorer is an interactive data analytics project exploring how CAO Round 1 course points have changed over time in Ireland. The project combines CAO course data from 2021–2025, cleans and standardises differences between yearly datasets, and prepares the data for interactive exploration using Python, Pandas, Plotly and Streamlit.

The dashboard is designed to allow users to explore which courses their Leaving Certificate points could have reached and compare the points requirements of selected courses across the previous five years, including courses from different higher education institutions.

Current work includes:

Cleaning and standardising CAO course datasets from 2021–2025
Consolidating yearly datasets into a single historical dataset
Handling AQA (All Qualified Applicants) courses separately from numerical points
Standardising changing course categories across years
Accounting for courses whose titles/categories have changed over time
Creating a course-level historical dataset using course code as the identifier
Preparing interactive filtering and visualisation using Streamlit and Plotly

The 2025 data is currently being used as a temporary stand-in for the 2026 CAO data while the updated data becomes available.
